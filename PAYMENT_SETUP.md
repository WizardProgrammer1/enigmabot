# Настройка Telegram Payments

## Шаг 1: Получение платежного токена

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/mybots`
3. Выберите вашего бота
4. Нажмите "Payments"
5. Выберите провайдера платежей (например, YooKassa, Stripe, или другой доступный в вашей стране)
6. Следуйте инструкциям для настройки провайдера
7. Скопируйте полученный токен

## Шаг 2: Обновление конфигурации

Откройте файл `src/config.py` и замените строку:

```python
PAYMENT_TOKEN = None  # Будет установлен через @BotFather
```

на:

```python
PAYMENT_TOKEN = 'ваш_платежный_токен_здесь'
```

## Шаг 3: Тестирование

1. Запустите бота
2. Отправьте команду `/start`
3. Выберите "💳 Тарифы"
4. Выберите любой тариф
5. Должно появиться окно оплаты

## Поддерживаемые провайдеры

Telegram автоматически подбирает подходящего провайдера в зависимости от страны пользователя:

- **Россия**: YooKassa, Sberbank, Tinkoff
- **США**: Stripe
- **Европа**: Stripe, SEPA
- **Другие страны**: Локальные провайдеры

## Важные замечания

1. **Тестовый режим**: При настройке провайдера вы можете использовать тестовые карты для проверки
2. **Комиссии**: Каждый провайдер берет свою комиссию (обычно 2-5%)
3. **Валюты**: Убедитесь, что провайдер поддерживает валюту RUB
4. **Документы**: Для некоторых провайдеров может потребоваться верификация

## Команды администратора для работы с заказами

- `/orders all [limit]` - все заказы
- `/orders pending` - ожидающие оплаты заказы  
- `/orders paid [limit]` - оплаченные заказы

## Структура базы данных

Заказы сохраняются в таблице `orders` со следующими полями:
- `id` - ID заказа
- `user_id` - ID пользователя
- `tariff_id` - ID тарифа
- `amount` - сумма в копейках
- `currency` - валюта
- `status` - статус (pending/paid)
- `created_at` - дата создания
- `paid_at` - дата оплаты
- `invoice_payload` - payload для идентификации
- `telegram_payment_charge_id` - ID платежа в Telegram
- `telegram_payment_provider_charge_id` - ID платежа у провайдера
