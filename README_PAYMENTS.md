### 1. Получить платежный токен
1. Откройте [@BotFather](https://t.me/BotFather)
2. Отправьте `/mybots`
3. Выберите вашего бота
4. Нажмите "Payments"
5. Выберите провайдера (Stripe, YooKassa, или другой)
6. Скопируйте токен

### 2. Установить токен
В файле `src/config.py` замените:
```python
PAYMENT_TOKEN = None
```
на:
```python
PAYMENT_TOKEN = 'ваш_токен_здесь'
```

### 3. Протестировать
```bash
python test_payments.py
python bot.py
```

## 🎯 Как это работает:

1. **Пользователь выбирает тариф** → создается заказ в БД
2. **Отправляется инвойс** → Telegram показывает окно оплаты
3. **Пользователь оплачивает** → Telegram отправляет уведомление
4. **Бот активирует подписку** → обновляет лимиты пользователя

## 📊 Админские команды:

- `/orders all [limit]` - все заказы
- `/orders pending` - ожидающие оплаты
- `/orders paid [limit]` - оплаченные заказы

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Установите ffmpeg:
- Windows: Скачайте с https://ffmpeg.org/download.html
- Linux: `sudo apt install ffmpeg`
- macOS: `brew install ffmpeg`

3. Настройте токен бота в `src/config.py`:
```python
API_TOKEN = 'ваш_токен_бота'
```

## Решение проблем

### Ошибка CUDA
Если возникает ошибка "CUDA device but torch.cuda.is_available() is False":
- Бот автоматически переключится на CPU
- Убедитесь, что установлен torch: `pip install torch`

### Медленная транскрипция
- На CPU транскрипция будет медленнее
- Для ускорения используйте GPU с CUDA
- Можно изменить модель в config.py (tiny, base, small, medium, large)

### Ошибки ffmpeg
- Убедитесь, что ffmpeg установлен и доступен в PATH
- Для Windows добавьте путь к ffmpeg в переменную PATH
