## 🔍 НОВАЯ ПРОБЛЕМА: "The related resource does not exist"

Эта ошибка означает, что Store ID или Variant ID не существуют в вашем аккаунте Lemon Squeezy.

1. **Запустите обновленный тестовый скрипт:**
   ```bash
   python test_lemonsqueezy.py
   ```

2. **Скрипт автоматически:**
   - Получит список ваших stores
   - Получит список ваших variants
   - Найдет правильные ID
   - Протестирует создание checkout

3. **Скопируйте правильные ID:**
   - Store ID (например: `5165974`)
   - Variant ID (например: `123456`)

4. **Обновите код бота:**
   - Замените Store ID в методе `create_checkout`
   - Замените Product ID в конструкторе
